Quantum Green Wave

Ambulances lose minutes at red lights. This project chooses which ambulance goes where, then sets the phase of 16 traffic signals for six 15-second slots so each ambulance meets green. The signal problem has 96 binary variables. Quantum circuits solve it in 12-qubit pieces, and a traffic simulator checks every plan.

The plan the solver produces

Rows are the 16 intersections, columns are six 15-second slots. Each cell is one qubit. Orange dots mark where an ambulance expects to cross (it covers a 150 m block in about 9 s, as measured in the simulator). A good plan puts green on the ambulance's axis in exactly those cells.

What the quantum part does

Every figure compares against a classical control that sees the same problem, so a result only counts when it beats luck or a simple rule.

Does it survive a traffic simulator?

The QUBO is a model. SUMO is the check. Each plan runs in a fresh simulation with the same demand for the same 160 s, three random seeds per scenario.

Late or early ambulances, and real hardware

Arrival times are never exact. The solver plans for a ±1 slot spread. Then the window circuits are costed on a real IBM chip layout.
